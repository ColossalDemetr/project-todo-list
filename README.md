# 📝 Todo List

A simple and clean Todo List app built with vanilla JavaScript.

## Features

- Create and manage multiple projects
- Add, delete todos with title, description, date and priority
- Mark todos as completed
- Data persists via localStorage

## Tech Stack

- HTML / CSS / JavaScript
- Webpack
